AP Study Path - Windows Instructions

1. Install Node.js 22 LTS or newer from https://nodejs.org
2. Double-click RUN-WEBSITE-WINDOWS.bat
3. Wait for it to install and start, then open http://localhost:5173 in Chrome.

Optional - turn on AI FRQ grading:
1. Copy .env.example to a new file named .env
2. Paste your Anthropic API key after ANTHROPIC_API_KEY=
3. Close the black window and run RUN-WEBSITE-WINDOWS.bat again.

Without a key, everything still works and FRQs use the free rubric estimate.
